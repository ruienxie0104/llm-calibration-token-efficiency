# R³-Bench 閱讀筆記

> Wang et al. (2026). arXiv: 2608.16033

## 核心內容

提出 R³-Bench，在共享總 token 預算下評估 LLM 的資源理性推理能力。

- 把 6 題組成一組，給一組共享預算
- 涵蓋數學、競技程式、抽象推理
- 建立 single-problem response curves 作為 oracle baseline
- 6 模型 × 72 條件

## 與本研究的關係

**重疊：** budget sensitivity 測量的概念類似——都使用不同 token 預算建立準確率曲線。

**差異：**
- R³-Bench 是 benchmark/評估框架，不是因果分析
- 沒有校準分析、沒有 IRT/LCAE、沒有 intervention
- 共享預算 vs 逐題固定預算（不同的資源限制形式）

## 影響

budget sensitivity 測量方法本身 novelty 下降，但「校準 × token 效率」交叉點仍安全。
