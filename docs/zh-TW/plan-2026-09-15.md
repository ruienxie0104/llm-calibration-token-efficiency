## Phase 1：Soft + IDS 實驗（最高優先）

### 為什麼要做

Soft Pilot 已證實兩件事：
1. Soft 下準確率遠高於 Hard（74% vs 0%）
2. Soft 下校準能力消失（差距趨近 0）

接下來要問：**在有 agency 的情境下，IDS 能不能改善 token 分配？** 如果在 soft 下 IDS 能同時改善校準和準確率，因果鏈就成立了。

### 實驗設計

| 參數 | 設定 |
|------|------|
| 模型 | GPT-OSS-120B + DeepSeek |
| 條件 | Soft QOQ（已有）vs Soft IDS（新跑） |
| Budgets | 256、512 |
| 題目 | 30 題 MATH-500 L3+L4（同一批） |
| Replicates | 3 |
| 規模 | 2 × 1 × 2 × 3 × 30 × 2 = 720 calls |
| 預計時間 | ~20 分鐘 |

### 實驗腳本

可以直接複製 `run_soft_pilot.py`，將 condition 改成 QOQ vs IDS（跟 `run_ids.py` 類似），只有 prompt 差別：

```
Soft QOQ: "Please complete within approximately N tokens..."
Soft IDS: "This problem is rated difficult. Please complete within N tokens..."
```

### 預期結果與判讀

| 結果 | 意義 |
|------|------|
| Soft IDS → 準確率 + 校準都改善 | **因果鏈成立** — 最強結果 |
| Soft IDS → 校準改善，準確率不變 | 跟 Hard IDS 一樣 — 因果鏈斷在別處 |
| Soft IDS → 兩者都不變 | IDS 對 soft 也無效 |
