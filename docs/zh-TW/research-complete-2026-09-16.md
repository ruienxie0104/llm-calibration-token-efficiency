## 第一章：研究動機與核心問題

### 1.1 背景

LLM 推理消耗大量 token，每個 API 呼叫都有成本。現有 adaptive reasoning 研究（如 Think Just Enough）假設模型信心可以直接作為推理深度的控制信號，但這個假設的基礎——模型信心的校準品質——很少被檢驗。

### 1.2 核心問題

> **校準品質能否幫助 LLM 更有效率地使用 token？**

這個問題從第一天到現在沒變。我們用了學姐的 LCAE/IRT 框架來測量校準品質，用 Controlled Budget Sweep 來測量 token 效率。

### 1.3 使用的方法

| 方法 | 來源 | 用途 |
|------|------|------|
| Brier Score | 文獻標準（Guo et al. 2017） | 傳統校準 baseline |
| LCAE（IRT-based） | 學姐（Chen et al. 2026） | IRT 校準品質測量 |
| Controlled Budget Sweep | 我們原創 | 固定 token 預算比較模型 |
| IDS（Item Difficulty Signal） | 學姐（Chen et al. 2026） | 改善校準的因果介入 |
| Process Mining | pm4py 工具 | 診斷推理行為序列 |

## 第二章：實驗設計

### 2.1 模型

| 模型 | 參數量 | 架構 | 角色 |
|------|--------|------|------|
| GPT-OSS-20B | 21B | Dense | 校準較差（小模型） |
| GPT-OSS-120B | 117B | Dense | 校準最好 |
| DeepSeek-V4-Flash | 158B | MoE | 能力最強 |
| GLM-5.2 | 756B | MoE | 最大模型 |

### 2.2 題目

MATH-500（Level 3-4），標準 benchmark，被 Think Just Enough、TALE 等廣泛使用。

### 2.3 預算設定

```
256 tokens → 極度壓縮（自然用量約 30%）
512 tokens → 中等壓縮（自然用量約 60%）
1024 tokens → 接近無限制（對照組）
```

## 第三章：實驗結果總覽

### 3.1 Phase 3 — Hard Constraint（4 模型 × 60 題 × 3 budgets × 3 reps）

```
                    ╔═══════════════════════════════════════╗
                    ║   準確率 vs Token 預算（Hard）        ║
                    ╠═══════════╤══════╤══════╤══════╤══════╣
                    ║  Model    │256   │512   │1024  │ LCAE ║
                    ╟───────────┼──────┼──────┼──────┼──────╢
                    ║ GPT-20B   │ 0.0% │19.4% │48.3% │0.341 ║
                    ╟───────────┼──────┼──────┼──────┼──────╢
                    ║ GPT-120B  │ 0.0% │17.2% │50.6% │0.247 ║
                    ╟───────────┼──────┼──────┼──────┼──────╢
                    ║ DeepSeek  │18.3% │49.4% │66.1% │0.303 ║
                    ╟───────────┼──────┼──────┼──────┼──────╢
                    ║ GLM-5.2   │ 0.0% │ 4.4% │36.7% │0.438 ║
                    ╚═══════════╧══════╧══════╧══════╧══════╝
```

#### 發現一：能力 θ ≠ 校準 LCAE

```
           ╔════════════╤════════╤════════╗
           ║ Model      │θ (能力)│LCAE    ║
           ╠════════════╪════════╪════════╣
           ║ DeepSeek   │ +0.65 │ 0.303  ║
           ╟────────────┼────────┼────────╢
           ║ GPT-120B   │ +0.00 │ 0.247  ║ ← 校準最好
           ╟────────────┼────────┼────────╢
           ║ GPT-20B    │ −0.09 │ 0.341  ║
           ╟────────────┼────────┼────────╢
           ║ GLM-5.2    │ −0.57 │ 0.438  ║
           ╚════════════╧════════╧════════╝
```

#### 發現二：Brier vs LCAE 排名不同

```
       ╔════════════╤══════════╤══════════╗
       ║ Model      │Brier(↓好)│LCAE(↓好) ║
       ╠════════════╪══════════╪══════════╣
       ║ DeepSeek   │  0.284 🥇│  0.303 🥈║
       ╟────────────┼──────────┼──────────╢
       ║ GPT-120B   │  0.320 🥈│  0.247 🥇║
       ╚════════════╧══════════╧══════════╝
```

#### 發現三：信心差距可做代理指標

```
GPT-120B（+25.5）> DeepSeek（+15.5）> GPT-20B（+7.3）> GLM-5.2（+3.4）
                  排序與 LCAE 一致
```

### 3.2 IDS Intervention（2 模型 × 2 條件 × 2 budgets × 3 reps）

```
╔══════════╤══════╤══════╤═══════════════╤═══════════════╗
║ Model    │Budg. │Cond  │ Brier(↓好)    │ Acc           ║
╠══════════╪══════╪══════╪═══════════════╪═══════════════╣
║ GPT-120B │ 512  │ QOQ  │     0.403     │     27.8%     ║
║ GPT-120B │ 512  │ IDS  │     0.370 ✅  │     27.8%     ║
╟──────────┼──────┼──────┼───────────────┼───────────────╢
║ DeepSeek │ 512  │ QOQ  │     0.273     │     57.8%     ║
║ DeepSeek │ 512  │ IDS  │     0.266 ✅  │     60.0%     ║
╚══════════╧══════╧══════╧═══════════════╧═══════════════╝
```

**IDS 改善了校準（Brier ↓），但準確率沒有顯著變化。** 因果鏈在校準改善這一步斷了。

### 3.3 PM 分析 — 為什麼 IDS 沒有效

```
╔══════════╤══════════╤══════════╤═══════╤═══════════╗
║ Model    │@256 步數 │@1024 步數│比例   │Answer@256 ║
╠══════════╪══════════╪══════════╪═══════╪═══════════╣
║ GPT-20B  │   1.1    │  11.0    │  10%  │   0.0%    ║
║ GPT-120B │   1.8    │  12.7    │  14%  │   0.0%    ║
║ DeepSeek │   2.3    │   6.6    │  35%  │   0.0%    ║
║ GLM-5.2  │   0.1    │   7.8    │   1%  │   0.0%    ║
╚══════════╧══════════╧══════════╧═══════╧═══════════╝
```

**結論：Hard 下模型不是在做分配決策，是被 `num_predict` 強制截斷。** 模型沒有 agency，IDS 沒有作用空間。

### 3.4 Soft Pilot — 兩種機制根本不同

```
╔═══════════════╤══════╤═══════════╤═══════════╤══════════╗
║ 五維對比      │      │   Hard    │   Soft    │ Winner  ║
╠═══════════════╪══════╪═══════════╪═══════════╪══════════╣
║ Acc @256      │      │   0-18%   │  74-80%   │  Soft 🏆║
╟───────────────┼──────┼───────────┼───────────┼──────────╢
║ Acc @512      │      │  17-49%   │  77-82%   │  Soft 🏆║
╟───────────────┼──────┼───────────┼───────────┼──────────╢
║ 校準差距      │      │  優       │  差 (→0)  │  Hard 🏆║
╟───────────────┼──────┼───────────┼───────────┼──────────╢
║ Model agency  │      │  無       │  有       │  Soft 🏆║
╟───────────────┼──────┼───────────┼───────────┼──────────╢
║ IDS 效果      │      │ Brier↓ Acc=│ 待測試   │  待測試 ║
╚═══════════════╧══════╧═══════════╧═══════════╧══════════╝
```

**最重要的發現：Soft 下準確率暴增，但校準能力消失。**

```
GPT-120B：
  Hard @512：差距 +35.0（知道自己對不對 ✅）
  Soft @512：差距 −0.5（不知道自己對不對 ❌）

DeepSeek：
  Hard @256：差距 +23.6
  Soft @256：差距 +0.0（全部 100%）
```

### 3.5 Soft + IDS — IDS 在 Soft 下也無效

```
╔══════════╤══════╤═══════════╤═══════════╤═══════════╗
║ Model    │Budg. │ Soft QOQ │ Soft IDS  │ 變化      ║
╠══════════╪══════╪═══════════╪═══════════╪═══════════╣
║GPT-120B  │ 256  │  74.4%    │  73.3%    │ ❌ 無變化 ║
║GPT-120B  │ 512  │  76.7%    │  76.7%    │ ❌ 無變化 ║
║DeepSeek  │ 256  │  80.0%    │  83.3%    │ ⚠️ 邊際   ║
║DeepSeek  │ 512  │  82.2%    │  83.3%    │ ❌ 無變化 ║
╚══════════╧══════╧═══════════╧═══════════╧═══════════╝
```

確認了 Kimiko 的預測：Soft 下校準已經消失（差距趨近 0），IDS 沒有作用空間。

## 第四章：故事線總串聯

```
核心問題：校準品質能否幫助 LLM 更有效率地使用 token？
  │
  ├─ Phase 3（Hard）
  │   發現校準 ≠ 能力、Brier ≠ LCAE
  │   但因果鏈不明（觀察性結果）
  │   ↓
  ├─ IDS（Hard）
  │   校準可改善，但準確率不變
  │   → 因果鏈斷了
  │   ↓ 為什麼斷？
  ├─ PM 分析
  │   Hard 下模型無 agency，只是被截斷
  │   → 需要讓模型有 agency 才能測試
  │   ↓
  ├─ Soft Pilot
  │   準確率暴增（0% → 74%），但校準消失
  │   → 關鍵發現：trade-off
  │   ↓ 那 IDS 能改善軟情境嗎？
  ├─ Soft + IDS
  │   IDS 在 soft 下也無效
  │   → 校準在 soft 下已無作用空間
  │   ↓
  └─ 最終結論：
      校準品質無法直接預測或改善 token 效率
      關鍵瓶頸在模型 agency — hard 下無 agency，
      soft 下有 agency 但校準訊號本身失效
```

## 第六章：下一步 — 方向 B

### 待解決的問題

Soft 下校準消失——能不能讓 soft 下同時保持高準確率和高校準？

### 可能的方法（依優先級）

| 方法 | 來源 | 創新性 | 成本 |
|------|------|--------|------|
| **Prospective vs Retrospective** | 行為經濟學靈感 | 中高 | ~360 calls |
| **CABStop 風格** | Calibration Drift Under Reasoning (arXiv Apr 2026) | 高 | 中 |
| **LCAE 套用到 Soft 數據** | 學姐方法延伸 | 高 | 免費（已有數據） |
| **Think Just Enough + LCAE** | EACL 2026 + 學姐 | 中 | 高 |

**最優先：把 LCAE 套用到 Soft 數據。** 這完全免費，而且如果 LCAE 在 soft 下仍然有效，學姐的方法就從「評估工具」升級成「解決方案的一部分」。
